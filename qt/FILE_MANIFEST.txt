================================================================================
快速开始
================================================================================

1. 编译前端
   - 使用 Qt Creator：打开 KudingJudge.pro → 构建 → 运行
   - 使用 CMake：mkdir build && cd build && cmake .. && cmake --build .
   - 使用 qmake：qmake KudingJudge.pro && make

2. 启动后端
   - Windows：双击 start_backend.bat
   - macOS/Linux：python backend.py

3. 运行应用
   - ./KudingJudge
