## 📖 简介

AutoKuding 是一款专为 **酷丁评测系统** 设计的自动化提交工具，支持题目提交、验证码自动识别、评测结果自动获取等功能，帮助编程学习者提高练习效率。

---

## ✨ 核心功能

### 🔐 登录管理
- 支持用户名/密码登录
- **记住密码**功能，下次使用无需重新输入
- 自动保存登录状态

### 📝 题目提交
- **测试提交** - 快速测试代码片段
- **题目提交** - 支持按题号提交
- 双模式提交：
  - 编辑器模式 - 内置代码编辑器
  - 文件模式 - 从本地文件选择

### 🔍 验证码自动识别
- 自动获取验证码图片
- **OCR 自动识别**验证码
- 支持 OCR 增强模式（提高准确率）
- 手动刷新验证码功能

### 💻 代码编辑器
- 内置 **CTkCodeBox** 代码渲染组件
- 支持 **语法高亮**
- 支持多种编程语言（C/C++/Python/Java）

### 🔓 智能解密
- 使用 **Selenium** 自动获取评测结果
- 支持本地 API 和远程服务双通道解密
- 自动轮询，等待评测完成
- 实时显示评测状态和得分

### 🌍 多语言支持
- 中文 / English 界面切换
- 设置中可自由选择语言

### ⚙️ 高级设置
- **Debug 模式** - 显示详细调试日志
- **本地 API URL** - 可配置自定义解密服务地址

## 🚀 技术栈

| 技术 | 用途 |
|------|------|
| Python | 主要开发语言 |
| CustomTkinter | 现代 GUI 界面 |
| Selenium | 浏览器自动化 |
| pytesseract | OCR 验证码识别 |
| Pillow/PIL | 图像处理 |
| CTkCodeBox | 代码编辑器组件 |
| requests | 网络请求 |

## 📦 使用方法

1. **运行** `AutoKuding.exe`
2. 在登录标签页输入用户名和密码
3. 点击「登录」按钮
4. 选择「测试提交」或「题目提交」
5. 输入代码，获取并识别验证码
6. 点击「提交」等待结果

---

## ⚠️ 注意事项

1. 首次运行需要安装 **Chrome 浏览器**（Selenium 依赖）
2. OCR 功能需要 **Tesseract-OCR** 支持
3. 请确保网络连接正常
